## 3. Почему может пропасть такая возможность?
Возможность подключения по SSH может пропасть, потому что iptables после установки может применить политику DROP для входящих соединений или заблокировать нестандартный порт 239, если правила явно не разрешают трафик на этот порт. Обычно разрешен только стандартный порт для SSH 22.

## 5. Это будет udp или tcp прот?
Это будет TCP порт. Протокол SSH использует именно TCP для обеспечения надежного, зашифрованного соединения с гарантией доставки данных.
## 6. Сохраняются ли записанные вами правила после перезагрузки?
Нет, правила iptables сбрасываются при перезагрузке.
